# tic_tac_toe_logic2-method-2-
# 🧠 Tic-Tac-Toe AI – Program 2 (Logic-2)

## Overview
This project implements a rule-based intelligent Tic-Tac-Toe game using Python.  
The AI dynamically evaluates the board and makes decisions using predefined strategic rules instead of stored move tables.

## AI Technique
Rule-Based Artificial Intelligence (Logic-2)

## Rules Used
1. Win if possible
2. Block opponent
3. Take center
4. Take a corner
5. Take a side

## Technologies
- Python
- Rule-Based AI
- Console-based interface

## Features
- Intelligent opponent
- Human-like reasoning
- Low memory usage
- Textbook-aligned implementation
